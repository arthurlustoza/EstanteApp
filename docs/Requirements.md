## Functional — v1 ()
- RF01: list saved books
- RF02: add book manually (title and author)
- RF03: search book online and save
- RF04: mark book as read
- RF05: delete book
- RF06: view details and write a note
- RF07: record current page
- RF08: rate the book from 1 to 5 stars

## Functional — v2 ()
- RF09: log daily reading minutes and set a daily goal
- RF10: show reading streak
- RF11: daily reminder notification
- RF12: save and share a user-typed quote

## Non-Functional
- RNF01: work offline (except for search)
- RNF02: light and dark theme
- RNF03: screen reader accessibility across all screens

## Out of Scope
Login and cloud synchronization
Reading books inside the app (EPUB/PDF reader)
